Python 기반 고성능 웹 API 프레임워크 학습하기

📚 FastAPI란?

FastAPI는 현대적이고 빠른 Python 웹 프레임워크입니다. 타입 힌트를 기반으로 자동 검증과 문서화를 제공합니다.

실행 명령어: uvicorn main:app --reload

기본 앱 구조

from fastapi import FastAPI app = FastAPI( title = 'FAST API', description = '기본기능 확인', version = '0.0.1' ) # 기본 라우터 @app.get('/') def index(): return {'message': '첫번째 화면'}

🛣️ 라우팅 방식

경로 파라미터

URL 경로의 일부로 데이터 전달

@app.get('/hello/{name}') def say_hello(name: str): return f"안녕하세요 {name}"
예시: http://localhost:8000/hello/홍길동

쿼리 파라미터

? 뒤에 key=value 형태로 전달

@app.get('/greet') def greet(name: str, age: int): return f'반갑습니다, {name}님'
예시: http://localhost:8000/greet?name=홍길동&age=35
⚠️ 차이점: 경로 파라미터는 필수값, 쿼리 파라미터는 선택값으로 사용 가능

✅ Pydantic 데이터 검증

Pydantic의 BaseModel을 사용하여 복잡한 데이터를 안전하게 받고 검증합니다.

기본 모델

from pydantic import BaseModel, Field class Item(BaseModel): name: str price: int @app.post('/item/simple') def create_item_simple(item: Item): return { 'message': f"{item.name}이(가) 추가되었습니다.", 'item': item }

검증 규칙이 있는 모델

class Product(BaseModel): name: str = Field(..., min_length=1, max_length=100) price: int = Field(..., gt=0) # gt: greater than (0보다 큼) description: Optional[str] = Field(None, max_length=500) is_stock: bool = Field(default=True)

Field 검증 옵션

  • ... - 필수 항목
  • gt - greater than (초과)
  • ge - greater equal (이상)
  • lt - less than (미만)
  • le - less equal (이하)
  • min_length - 최소 길이
  • max_length - 최대 길이

Optional 타입

선택적 필드는 Optional을 사용합니다.

from typing import Optional description: Optional[str] = None
💡 중요: GET은 "조회"용, POST는 "생성/전송"용입니다. GET은 상태를 바꾸지 않고, POST는 상태를 변경합니다.

@app.put('/todos/{id}', response_model=TodoResponse) def update_todo(id: int, update_data: TodoUpdate): for todo in todos_db: if todo.id == id: todo.modified_at = datetime.now().strftime('%Y-%m-%d %H:%M:%S') if update_data.title is not None: todo.title = update_data.title if update_data.completed is not None: todo.completed = update_data.completed return todo

4️⃣ 삭제 (Delete)

@app.delete('/todos/{id}', status_code=status.HTTP_204_NO_CONTENT) def delete_todo(id: int): for index, todo in enumerate(todos_db): if todo.id == id: todos_db.pop(index) return

🔧 고급 기능

CORS 설정

다른 도메인(프론트엔드)에서 API 호출을 허용하는 설정입니다.

from fastapi.middleware.cors import CORSMiddleware app.add_middleware( CORSMiddleware, allow_origins=['*'], # 모든 도메인 허용 allow_credentials=True, # 쿠키/인증정보 포함 요청 allow_methods=['*'], # 모든 HTTP method allow_headers=['*'] # 모든 헤더 )

정적 파일 제공

from fastapi.staticfiles import StaticFiles app.mount("/static", StaticFiles(directory="static"), name="static")

자동 문서화

FastAPI는 자동으로 API 문서를 생성합니다:
  • Swagger UI: http://127.0.0.1:8000/docs
  • ReDoc: http://127.0.0.1:8000/redoc

Status Code 활용

200 OK

성공적인 GET, PUT 요청

201 Created

성공적인 POST 요청 (생성)

204 No Content

성공적인 DELETE 요청

404 Not Found

데이터 모델 예시

class TodoCreate(BaseModel): '''생성용 모델 - 입력값만''' title: str = Field(..., min_length=1, max_length=100) description: Optional[str] = Field(None, max_length=500) class TodoResponse(BaseModel): '''응답용 모델 - 전체 데이터''' id: int title: str description: Optional[str] completed: bool created_at: str modified_at: Optional[str] = None class TodoUpdate(BaseModel): '''수정용 모델 - 모든 필드 선택적''' title: Optional[str] = Field(None, min_length=1, max_length=100) description: Optional[str] = Field(None, max_length=500) completed: Optional[bool] = None
✨ 모범 사례:
  • 입력, 출력, 수정용 모델을 분리하여 사용
  • 적절한 HTTP 메서드와 상태 코드 사용
  • 명확한 에러 메시지 제공
  • API 문서에 예시 포함
