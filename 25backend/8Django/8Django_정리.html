🗄️ 데이터 모델 (Models)

프로젝트는 4개의 핵심 모델로 구성되어 있습니다:

1️⃣ Category (카테고리)

게시글을 분류하는 카테고리 모델입니다.

name: 카테고리 이름 (고유값)
slug: URL 친화적 식별자
description: 카테고리 설명
created_at: 생성일시
💡 특징: slug는 name을 기반으로 자동 생성됩니다. 예: "장고 튜토리얼" → "장고-튜토리얼"

2️⃣ Tag (태그)

게시글에 다중으로 붙일 수 있는 태그 모델입니다.

name: 태그 이름 (고유값)
slug: URL 친화적 식별자
created_at: 생성일시
💡 관계: Post와 다대다(ManyToMany) 관계

3️⃣ Post (게시글)

블로그의 핵심인 게시글 모델입니다.

title: 제목
slug: URL 식별자
content: 본문 내용
excerpt: 요약 (최대 500자)
author: 작성자 (User 외래키)
category: 카테고리 (Category 외래키)
tags: 태그들 (Tag 다대다)
status: 상태 (draft/published)
views: 조회수
featured: 주요 게시글 여부
✨ 특별 기능:
  • comment_count: 댓글 수를 반환하는 프로퍼티
  • increment_views(): 조회수를 증가시키는 메서드

4️⃣ Comment (댓글)

게시글에 달리는 댓글과 대댓글을 관리하는 모델입니다.

post: 게시글 (Post 외래키)
author: 작성자 (User 외래키)
content: 댓글 내용
parent: 부모 댓글 (대댓글인 경우)
is_approved: 승인 여부
💡 대댓글 구조: parent 필드를 통해 자기 참조(self-referencing)로 대댓글 구현

🔄 시리얼라이저 (Serializers)

시리얼라이저란? Python 객체와 JSON 형식 간의 변환을 담당하는 중요한 컴포넌트입니다.

주요 시리얼라이저들

UserSerializer

class UserSerializer(serializers.ModelSerializer): post_count = serializers.SerializerMethodField() fields = ['id', 'username', 'email', 'post_count']

역할: 사용자 정보와 작성한 게시글 수를 반환

CategorySerializer & TagSerializer

class CategorySerializer(serializers.ModelSerializer): post_count = serializers.SerializerMethodField() fields = ['id', 'name', 'slug', 'description', 'post_count', 'created_at']

역할: 카테고리/태그 정보와 해당하는 게시글 수를 반환

CommentSerializer

class CommentSerializer(serializers.ModelSerializer): author = UserSerializer(read_only=True) replies = serializers.SerializerMethodField() # 댓글 유효성 검증 def validate_content(self, value): if len(value) < 2: raise ValidationError("최소 2자 이상") if len(value) > 500: raise ValidationError("최대 500자까지") return value

특징: 대댓글(replies)을 재귀적으로 포함하며, 댓글 길이 검증 기능 포함

PostListSerializer vs PostDetailSerializer

구분 용도 특징
PostListSerializer 게시글 목록 조회 excerpt(요약)만 포함, 가벼운 데이터
PostDetailSerializer 게시글 상세 조회 content(전체 내용), comments(댓글) 포함
⚠️ 성능 최적화: 목록 조회 시 불필요한 데이터를 줄여 응답 속도를 향상시킵니다.

🎯 뷰셋 (ViewSets)

ViewSet이란? 관련된 여러 view(목록, 상세, 생성, 수정, 삭제)를 하나의 클래스로 묶은 강력한 도구입니다.

🔍 ViewSet의 종류

CategoryViewSet & TagViewSet

class CategoryViewSet(viewsets.ReadOnlyModelViewSet): queryset = Category.objects.all() serializer_class = CategorySerializer @action(detail=True, methods=['get']) def posts(self, request, pk=None): # 특정 카테고리의 게시글 목록 반환

특징: ReadOnlyModelViewSet - 읽기 전용 (조회만 가능)

PostViewSet (가장 복잡하고 중요!)

📌 기본 CRUD 기능

메서드 기능 설명
GET list() 게시글 목록 조회
GET retrieve() 특정 게시글 상세 조회
POST create() 게시글 생성
PUT update() 게시글 수정

🎨 커스텀 액션들

@action publish: 게시글을 발행 상태로 변경
@action unpublish: 게시글을 임시저장 상태로 변경
@action my_posts: 내가 작성한 게시글 목록
@action drafts: 임시저장된 게시글 목록
@action comments: 특정 게시글의 댓글 목록

🔒 권한 및 필터링

def get_queryset(self): # 발행된 게시글만 표시 # 단, 작성자는 본인의 모든 글을 볼 수 있음 if self.request.user.is_authenticated: return Post.objects.filter( Q(status='published') | Q(author=self.request.user) ) else: return Post.objects.filter(status='published')

CommentViewSet

class CommentViewSet(viewsets.ModelViewSet): queryset = Comment.objects.select_related('author', 'post') def get_queryset(self): # 쿼리 파라미터로 특정 게시글의 댓글만 필터링 가능 post_id = self.request.query_params.get('post') if post_id: return queryset.filter(post_id=post_id)

특징: URL 쿼리 파라미터를 통해 특정 게시글의 댓글만 조회 가능

⚙️ 프로젝트 설정 (Settings)

🔐 인증 설정

REST_FRAMEWORK = { 'DEFAULT_AUTHENTICATION_CLASSES': [ 'rest_framework.authentication.TokenAuthentication', 'rest_framework.authentication.SessionAuthentication', ], 'DEFAULT_PERMISSION_CLASSES': [ 'rest_framework.permissions.IsAuthenticatedOrReadOnly', ], }
📌 인증 방식:
  • TokenAuthentication: API 요청 시 토큰을 헤더에 포함하여 인증
  • SessionAuthentication: 웹 브라우저에서 세션 기반 인증
  • IsAuthenticatedOrReadOnly: 읽기는 누구나, 쓰기는 로그인 사용자만

📄 페이지네이션 설정

REST_FRAMEWORK = { 'DEFAULT_PAGINATION_CLASS': 'rest_framework.pagination.PageNumberPagination', 'PAGE_SIZE': 10, }

한 페이지에 10개씩 데이터를 반환합니다.

🔍 필터링 & 검색 설정

REST_FRAMEWORK = { 'DEFAULT_FILTER_BACKENDS': [ 'django_filters.rest_framework.DjangoFilterBackend', 'rest_framework.filters.SearchFilter', 'rest_framework.filters.OrderingFilter', ], }
✨ 기능:
  • DjangoFilterBackend: 필드 기반 필터링
  • SearchFilter: 검색 기능
  • OrderingFilter: 정렬 기능

🎓 핵심 개념 정리

1. Django REST Framework의 4대 핵심 요소

① Model (모델)

데이터베이스 테이블을 정의하는 클래스입니다.

class Post(models.Model): title = models.CharField(max_length=200) content = models.TextField()

② Serializer (시리얼라이저)

Python 객체 ↔ JSON 변환을 담당합니다.

class PostSerializer(serializers.ModelSerializer): class Meta: model = Post fields = ['id', 'title', 'content']

③ ViewSet (뷰셋)

API 로직을 처리하는 컨트롤러입니다.

class PostViewSet(viewsets.ModelViewSet): queryset = Post.objects.all() serializer_class = PostSerializer

④ Router (라우터)

URL을 자동으로 생성해줍니다.

router = DefaultRouter() router.register('posts', PostViewSet)

2. 데이터 흐름 이해하기

📥 요청 흐름 (Request)

클라이언트가 GET /api/posts/ 요청
↓
URL 라우터가 PostViewSet으로 연결
↓
ViewSet이 queryset에서 데이터 조회
↓
Serializer가 Python 객체 → JSON 변환
↓
JSON 응답을 클라이언트에게 반환

3. 성능 최적화 기법

select_related() - 1대1, 다대1 관계

# N+1 쿼리 문제를 방지 Post.objects.select_related('author', 'category')

SQL JOIN을 사용하여 한 번의 쿼리로 관련 데이터를 가져옵니다.

prefetch_related() - 다대다 관계

# 태그 정보를 효율적으로 가져오기 Post.objects.prefetch_related('tags')

별도의 쿼리로 관련 데이터를 가져온 후 Python에서 조인합니다.

4. 보안 기능

기능 설명
인증 (Authentication) Token 또는 Session 기반으로 사용자 확인
권한 (Permission) IsAuthenticatedOrReadOnly - 읽기는 누구나, 쓰기는 인증 필요
작성자 검증 perform_create()에서 자동으로 작성자 설정
데이터 검증 Serializer의 validate_* 메서드로 입력값 검증
