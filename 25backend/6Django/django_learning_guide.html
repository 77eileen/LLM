🔗 URLs: 경로 매핑

역할: URL 주소를 보고 어느 View 함수를 실행할지 결정합니다.

mysite/urls.py (프로젝트 메인)

from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('blog/', include('blog.urls')),  # blog/로 시작하면 blog 앱으로!
]

blog/urls.py (앱 내부)

from django.urls import path
from . import views

app_name = 'blog'

urlpatterns = [
    path('', views.index),                    # blog/
    path('<int:question_id>/', views.detail),   # blog/1/
    path('register/answer/<int:question_id>/', views.answer_create),
]

연결 예시

👉 blog/5/ 접속 시:

1. mysite/urls.py가 "blog/" 감지

2. blog/urls.py로 넘어감

3. <int:question_id> 패턴이 5를 잡아냄

4. views.detail(request, question_id=5) 실행!

⚙️ Views: 요청 처리 로직

역할: 실제 작업을 수행합니다. DB 조회, 계산, 템플릿 렌더링 등

from django.shortcuts import render
from .models import Question

# 질문 목록 보기
def index(request):
    question_list = Question.objects.order_by('-create_at')  # DB에서 질문 조회
    context = {'question_list': question_list}
    return render(request, 'blog/question_list.html', context)

# 질문 상세 보기
def detail(request, question_id):
    question = Question.objects.get(id=question_id)  # 특정 질문 가져오기
    context = {'question': question}
    return render(request, 'blog/question_detail.html', context)

# 답변 등록
def answer_create(request, question_id):
    question = Question.objects.get(id=question_id)
    question.answer_set.create(
        content=request.POST.get('content'),
        create_at=timezone.now()
    )
    return redirect('blog:detail', question_id=question.id)

View가 하는 일

1. Models를 통해 데이터베이스에서 데이터 가져오기

2. 데이터 가공 (정렬, 필터링 등)

3. Templates에 데이터 전달하여 HTML 생성

4. 결과를 사용자에게 반환

🗄️ Models: 데이터 구조 정의

역할: 데이터베이스 테이블 구조를 정의하고 데이터를 다룹니다.

from django.db import models

# 질문 테이블
class Question(models.Model):
    subject = models.CharField(max_length=200)     # 제목
    content = models.TextField()                   # 내용
    create_at = models.DateTimeField()             # 작성일

# 답변 테이블
class Answer(models.Model):
    question = models.ForeignKey(Question, on_delete=models.CASCADE)
    # ↑ Question과 연결! 질문이 삭제되면 답변도 삭제
    content = models.TextField()
    create_at = models.DateTimeField()

ForeignKey의 마법 ✨

question.answer_set.all()

→ 한 질문에 달린 모든 답변을 자동으로 가져옵니다!

→ Django가 자동으로 만들어주는 "역방향 관계"


answer.question

→ 답변이 속한 질문을 가져옵니다 (정방향 관계)

데이터베이스와의 대화

# 모든 질문 가져오기
Question.objects.all()

# 특정 질문 가져오기
Question.objects.get(id=1)

# 최신순 정렬
Question.objects.order_by('-create_at')

# 질문의 답변들 가져오기
question.answer_set.all()

🎨 Templates: HTML 렌더링

역할: View에서 받은 데이터를 HTML에 표시합니다.

question_list.html (질문 목록)

<h1>질문목록</h1>
{% if question_list %}
    <ul>
    {% for question in question_list %}
        <li>
            <a href="{% url 'blog:detail' question.id %}">
                {{ question.subject }}  <!-- View에서 받은 데이터 -->
            </a>
        </li>
    {% endfor %}
    </ul>
{% else %}
    <p>질문이 없습니다.</p>
{% endif %}

question_detail.html (질문 상세)

<p>{{ question.content }}</p>
<p>{{ question.create_at }}</p>

<h5>{{ question.answer_set.count }} 개의 답변</h5>
<ul>
    {% for answer in question.answer_set.all %}
        <li>{{ answer.content }}</li>
    {% endfor %}
</ul>

<!-- 답변 작성 폼 -->
<form action="{% url 'blog:answer_create' question.id %}" method="post">
    {% csrf_token %}
    <textarea name="content"></textarea>
    <button type="submit">등록</button>
</form>

템플릿 태그 설명

{{ 변수 }} - 변수 출력

{% for %} - 반복문

{% if %} - 조건문

{% url %} - URL 생성

{% csrf_token %} - 보안 토큰
