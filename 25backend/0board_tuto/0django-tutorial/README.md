# Django 게시판 만들기 튜토리얼

## 📚 소개

이 튜토리얼은 Django 초심자도 따라하면서 완전한 기능을 갖춘 게시판을 만들 수 있도록 구성되었습니다.
모든 단계를 자세히 설명하고, 실제로 동작하는 코드를 제공합니다.

## 🎯 학습 목표

이 튜토리얼을 완료하면 다음을 배울 수 있습니다:

- Django 프로젝트 설정 및 구조 이해
- Django 모델(Model)을 사용한 데이터베이스 설계
- Django 뷰(View)와 URL 라우팅
- Django 템플릿(Template)을 사용한 화면 구성
- CRUD (Create, Read, Update, Delete) 기능 구현
- 사용자 인증 (회원가입, 로그인, 로그아웃)
- 댓글 기능
- 검색 및 페이지네이션
- CSS를 이용한 스타일링

## 🚀 시작하기

### 방법 1: 처음부터 배우기
[Part 1: 환경 설정 및 프로젝트 생성](./Part1-Setup.md) 문서부터 시작하세요!

### 방법 2: 완성된 코드 실행하기

이미 완성된 프로젝트 코드를 다운로드하여 바로 실행해볼 수 있습니다.

#### 1단계: 프로젝트 다운로드

```bash
git clone <repository-url>
cd django-tutorial
```

#### 2단계: Python 가상환경 생성 및 활성화

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

#### 3단계: Django 설치

```bash
pip install django
```

#### 4단계: 프로젝트 디렉토리로 이동

```bash
cd myboard
```

#### 5단계: 데이터베이스 마이그레이션

```bash
python manage.py migrate
```

#### 6단계: 관리자 계정 생성 (선택사항)

```bash
python manage.py createsuperuser
```

사용자 이름, 이메일, 비밀번호를 입력하세요.

#### 7단계: 개발 서버 실행

```bash
python manage.py runserver
```

#### 8단계: 브라우저에서 확인

웹 브라우저를 열고 다음 주소로 접속하세요:
- 메인 페이지: http://127.0.0.1:8000/
- 관리자 페이지: http://127.0.0.1:8000/admin/

#### 서버 종료

서버를 종료하려면 터미널에서 `Ctrl + C`를 누르세요.
