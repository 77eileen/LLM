👤 User → Post (1:N)

설명: 한 명의 유저가 여러 개의 글을 작성할 수 있습니다.

Django 코드:

author = models.ForeignKey(User, on_delete=models.CASCADE, related_name='posts')

역참조: user.posts.all() - 유저가 작성한 모든 글

삭제 정책: User 삭제 시 → 모든 Post도 함께 삭제 (CASCADE)

📁 Category → Post (1:N)

설명: 하나의 카테고리에 여러 개의 글이 속할 수 있습니다.

Django 코드:

category = models.ForeignKey(Category, on_delete=models.SET_NULL, blank=True, null=True, related_name='posts')

역참조: category.posts.all() - 카테고리의 모든 글

삭제 정책: Category 삭제 시 → Post의 category는 NULL로 설정 (SET_NULL)

🏷️ Tag ↔ Post (N:M)

설명: 하나의 글에 여러 태그를 붙일 수 있고, 하나의 태그는 여러 글에 사용될 수 있습니다.

Django 코드:

tags = models.ManyToManyField(Tag, blank=True, related_name='posts')

사용 예시:

post.tags.add(tag1, tag2) # 글에 태그 추가
tag.posts.all() # 해당 태그가 붙은 모든 글

📝 Post → Comment (1:N)

설명: 하나의 글에 여러 개의 댓글이 달릴 수 있습니다.

Django 코드:

post = models.ForeignKey(Post, on_delete=models.CASCADE, related_name='comments')

역참조: post.comments.all() - 글의 모든 댓글

삭제 정책: Post 삭제 시 → 모든 Comment도 함께 삭제 (CASCADE)

🔖 Bookmark / ❤️ Like (중복 방지)

설명: 한 유저는 같은 글에 북마크/좋아요를 단 한 번만 할 수 있습니다.

Django 코드:

class Meta:
    unique_together = ('post', 'user') # 중복 방지

사용 예시:

post.bookmarks.count() # 북마크 개수
post.likes.count() # 좋아요 개수
user.bookmarks.all() # 유저가 북마크한 모든 글

📝 글 작성하기

# 1. 새 글 작성
post = Post.objects.create(
    title="Django 튜토리얼",
    content="Django는 파이썬 웹 프레임워크입니다.",
    author=user, # User 객체
    category=category, # Category 객체
    published=True
)

# 2. 태그 추가 (M2M)
post.tags.add(tag1, tag2, tag3)

# 3. 조회수 증가
post.views += 1
post.save()

🔍 데이터 조회하기

# 1. 유저가 작성한 모든 글
user_posts = user.posts.all()

# 2. 카테고리의 모든 글
category_posts = category.posts.filter(published=True)

# 3. 태그가 붙은 글들
tagged_posts = tag.posts.all()

# 4. 글의 모든 댓글
comments = post.comments.all().order_by('-created_at')

# 5. 글의 좋아요 개수
like_count = post.likes.count()

# 6. 유저가 좋아요한 글들
liked_posts = Post.objects.filter(likes__user=user)

💬 댓글 달기

# 댓글 작성
comment = Comment.objects.create(
    post=post, # Post 객체
    author=user, # User 객체
    content="좋은 글 감사합니다!"
)

# 특정 글의 댓글 가져오기
post_comments = post.comments.all()

🔖 북마크 / ❤️ 좋아요

# 북마크 추가 (중복 체크)
bookmark, created = Bookmark.objects.get_or_create(
    post=post,
    user=user
)
if created:
    print("북마크 추가됨")
else:
    print("이미 북마크한 글입니다")

# 좋아요 토글
like, created = Like.objects.get_or_create(
    post=post,
    user=user
)
if not created:
    like.delete() # 이미 좋아요한 경우 취소

# 유저가 이 글을 좋아요 했는지 확인
has_liked = post.likes.filter(user=user).exists()

🔍 복잡한 쿼리 예시

# 1. 특정 카테고리의 인기 글 (좋아요 10개 이상)
popular_posts = Post.objects.filter(
    category=category,
    published=True
).annotate(
    like_count=Count('likes')
).filter(like_count__gte=10)

# 2. 유저가 작성한 글 중 댓글이 많은 순
user_popular = user.posts.annotate(
    comment_count=Count('comments')
).order_by('-comment_count')

# 3. 특정 태그를 가진 글들의 평균 조회수
from django.db.models import Avg
avg_views = tag.posts.aggregate(Avg('views'))
